## 📖 What is CodeCrafters?

**CodeCrafters** is an AI-powered learning and productivity platform built to help students
learn smarter, stay organized, and track their academic progress from one unified workspace.

It combines AI-powered learning tools with productivity features such as **AI Tutor,**
**Flashcards, Quizzes, Study Planning, Notes, Focus Sessions, and Learning Analytics**.

---

## 🚀 Core Features

### 🤖 AI Tutor

An interactive AI-powered study assistant that helps students understand concepts,
ask questions, and receive personalized explanations.

- Gemini AI integration
- Conversational learning interface
- Markdown-based responses
- Context-aware learning assistance

### 🧠 Smart Flashcards

An interactive flashcard system for creating and reviewing study material.

- AI-assisted flashcard generation
- Interactive card flipping
- Study progress tracking
- Persistent data storage

### 📝 Smart Notes

A focused workspace for creating and organizing academic notes.

- Create and manage notes
- Persistent storage
- Clean distraction-free interface

### 📅 Study Planner

A productivity system designed to help students organize their academic workload.

- Task management
- Study scheduling
- Progress tracking
- Interactive dashboard

### 🎯 Focus Timer

A dedicated study timer designed to help students maintain focused study sessions.

- Custom study sessions
- Countdown timer
- Productivity tracking

### 📊 Learning Analytics

Visual insights into study activity and progress.

- Progress visualization
- Study statistics
- Interactive charts
- Performance overview

### 🧩 AI Quiz

An AI-powered quiz experience for testing knowledge and reinforcing learning.

- Dynamic questions
- Interactive quiz interface
- Score tracking
- Learning-oriented feedback
